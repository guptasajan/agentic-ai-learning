# Agentic AI Learning Journey 🚀

A hands-on learning repository documenting my journey from Python fundamentals to building Agentic AI applications.

I'm learning Agentic AI step by step using Python, Ollama, Qwen3, embeddings, ChromaDB, RAG, and tool calling.

## 🛠️ Tech Stack

- Python
- Ollama
- Qwen3 (1.7B)
- ChromaDB
- nomic-embed-text
- Git & GitHub
